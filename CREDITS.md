## Inspiration (ideas and measurements only, no code copied)
- **Visual Pinball X** and **Visual Pinball Engine** (https://github.com/vpinball): table measurements, gates,
  ramps and rubber behaviour were studied to make the physics realistic. No line of their code is included.
