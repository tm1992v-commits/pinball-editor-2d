# Security

If you find a security problem (for example in the export or release features, or a way to run code from a table
file), **do not open a public issue**: write to **themeloohgames@gmail.com** with a description and, if possible,
the steps to reproduce it. You will get an answer as soon as possible; the fix will be released and credited
(unless you prefer to stay anonymous).

Scope: the editor, the game runtime and the release tools in this repository. Pinballs made by other people are
the responsibility of their authors.
